# 沉浸翻译（自用）

英文网页双语对照翻译：Chrome 内置本地翻译秒出初稿，大模型后台流式精翻并替换。

## 安装

1. `pnpm install && pnpm build`
2. 打开 `chrome://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选择 `.output/chrome-mv3`
3. 点插件图标 → 「下载本地翻译模型」（只需一次）
4. （可选）插件图标 → 设置：填写 OpenAI 兼容接口的地址、API Key、模型，点「测试连接」

## 使用

| 操作 | 快捷键 |
| --- | --- |
| 开关当前页翻译 | Alt+A（macOS 为 Option+A） |
| 双语对照 ⇄ 只看译文 | Alt+S（macOS 为 Option+S） |

快捷键可在 `chrome://extensions/shortcuts` 修改。半透明的是本地初稿，变成正常颜色说明大模型精翻已完成。

## 开发

- `pnpm dev`：开发模式（自动打开带插件的浏览器，热更新）
- `pnpm test` / `pnpm test:coverage`：单元与集成测试
- `pnpm test:e2e`：端到端测试（模拟大模型）

## 首次安装后请手动确认本地翻译可用

本地翻译依赖 Chrome 内置的 `Translator` API，是否能在内容脚本的隔离世界中正常工作无法用自动化脚本验证（正版 Chrome 155 会拒绝通过命令行参数加载扩展，自动化测试只能用 Playwright 自带的 Chromium，不能代表正版 Chrome 的行为）。首次安装后请手动确认一遍：

1. `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `.output/chrome-mv3`
2. 点插件图标，若本地翻译显示「模型未下载」，点「下载本地翻译模型」，等待下载完成（可能需要几分钟）
3. 打开任一英文网页，确认几乎立刻出现半透明译文
4. 若本地译文始终不出现：在该网页的控制台执行 `'Translator' in self`
   - 返回 `true` 但仍不出译文：是别的逻辑问题，可反馈排查
   - 返回 `false`：说明 Chrome 内置翻译 API 在内容脚本里不可用，当前版本没有退路（设计文档 4.3 的 offscreen document 方案未实现），本地翻译功能在你的环境下暂不可用，仅大模型精翻可用

## 已知限制

- 仅英译中；仅正版 Chrome 138+
- 本地翻译在内容脚本隔离世界中的可用性未被自动化验证过，需按上文手动确认一次
- 译文中不保留段内链接/加粗（双语模式可点原文链接）
- 精翻缓存不自动清理
